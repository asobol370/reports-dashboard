# Як зробити звіт клієнту з цього шаблону

Цей шаблон — веб-дашборд для тижневих/місячних звітів клієнтам за Google Ads.
Не потрібен API-доступ. Все, що потрібно — CSV/Excel з Google Ads UI + Claude.

---

## Крок 1. Завантажити цей шаблон

Скачати папку `_template/` цілком (Download ZIP з github або клон репо).
Перейменувати папку в назву клієнта — наприклад `_template/` → `zooshop/`.

Всередині вже є:

```
zooshop/
├── index.html          # весь UI/JS — не змінювати
├── data.json           # data (демо-дані на старті — замінити на реальні)
├── logo-agency.png     # ⚠️ замінити на СВІЙ лого агенції (той же файл!)
└── favicon-32.png      # (за бажанням — свій favicon)
```

Плюс покласти лого клієнта — файлом з тим іменем, яке буде в `data.json` (за замовчуванням `logo-client.png`).

---

## Крок 2. Вивантажити дані з Google Ads

Це найдовший крок. Треба зібрати CSV-и по кожному звітному періоду (тиждень / місяць).

### 2а. Overall метрики по періоду

У Google Ads UI:
1. Обрати клієнтський акаунт
2. Ліве меню → **Кампанії** (або одразу **Ефективність** → **Кампанії**)
3. Період справа зверху — виставити потрібний тиждень/місяць
4. **Segment → День** (кнопка «Сегмент» → «День») — щоб у CSV була колонка з датою і daily-розбивка.
5. **Змінити стовпці** (кнопка «Стовпці» → «Змінити стовпці») — увімкнути:
   - Витрати
   - Покази
   - Кліки
   - CTR
   - Сер. ціна за клік
   - Конверсії
   - Вартість/конверсія
   - Значення конверсії
   - ROAS (значення конверсії / витрати)
   - Частка показів у пошуку (Impression Share)
   - Частка показів у верхній частині сторінки
   - Частка показів на найпершій позиції
6. **Завантажити** (⬇️) → **CSV** (або Excel)

Файл назвати `week-DD-DD-MM.csv` або `month-MM-YYYY.csv` — щоб не плуталось.

### 2б. Розбивка по conversion actions

Якщо клієнт вважає покупки = сума кількох дій (напр. Purchase + Generate Lead):
1. Кампанії → «Сегмент» → **Конверсії → Дія-конверсія**
2. Завантажити CSV з тим же періодом

Так буде видно скільки саме покупок припадає на кожну дію.

### 2в. Add to Cart (за бажанням)

Аналогічно — сегмент «Дія-конверсія», експортувати CSV де видно значення для `add_to_cart` action.

**Мінімум для роботи** — тільки CSV з кроку 2а. Кроки 2б і 2в потрібні якщо клієнт має нестандартну модель конверсії або хоче Add to Cart як окрему метрику.

---

## Крок 3. Згенерувати `data.json` через Claude

Відкрити [claude.ai](https://claude.ai) (Sonnet або Opus — байдуже).

Скопіювати текст з [`CLAUDE_PROMPT.md`](CLAUDE_PROMPT.md) — це готовий prompt.
Прикріпити всі CSV, які зібрали на кроці 2 (можна кілька — за різні тижні/місяці).

Claude поверне `data.json` файлом.

Замінити свій `data.json` у папці на новий (перезаписати).

Перевірити локально — відкрити `index.html` в браузері (подвійним кліком).
Ввести пароль (за замовчуванням `change-me` — див. Крок 4).

---

## Крок 4. Налаштувати пароль і клієнтські поля

Відкрити `index.html` у текстовому редакторі, знайти рядок:

```js
const PASSWORD = 'change-me';
```

Замінити `change-me` на свій пароль (напр. `zooshop2026`). Зберегти.

У `data.json` перевірити:
- `client.name` — назва клієнта
- `client.logo` — ім'я файлу лого клієнта (поклали поряд)
- `agency.name` — назва вашої агенції
- `agency.logo` — ім'я файлу вашого лого

## Крок 5. Опублікувати клієнту

Два варіанти на вибір:

### Простіший — Netlify Drop (без git)

1. Відкрити [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетягнути ВСЮ папку клієнта (`zooshop/`) на сторінку
3. Netlify видасть URL типу `https://random-name-1234.netlify.app`
4. При бажанні — Site settings → Change site name → зробити `zooshop-reports.netlify.app`
5. Надіслати клієнту URL + пароль

Оновлення: коли з'явиться нова неділя — згенерувати новий `data.json` через Claude, перетягнути папку ще раз на Netlify Drop — оновиться той же URL.

### Серйозніший — GitHub Pages

1. Створити приватний або публічний GitHub-репо (напр. `<username>/reports-zooshop`)
2. Push з локальної папки
3. Settings → Pages → Deploy from branch main / (root)
4. URL буде `<username>.github.io/reports-zooshop/`
5. За бажанням — підключити свій домен

---

## Оновлення щотижнево

Раз на тиждень:
1. Вивантажити свіжі CSV з Google Ads (Крок 2)
2. Дати Claude через `CLAUDE_PROMPT.md` (Крок 3)
3. Перезалити файл на Netlify Drop або git push (Крок 5)

Той же URL клієнту — просто оновлені дані.

---

## Що включено в дашборд

- 4 primary KPI (Виручка / Витрати / ROAS / Покупок) + 4 secondary (CPA / Ср.чек / Кф.конверсії / CPC)
- Клік по картці → додає метрику на графік (макс 4 одночасно)
- Toggle Тиждень / Місяць + archive dropdown (свіжі періоди зверху)
- Таблиця 10 метрик періоду з порівнянням до попереднього
- Кампанії accordion — коротка summary + повний деталізований breakdown з IS/Top/First (для Search)
- Пароль-гейт на клієнті (client-side, символічна захист)

---

## Обмеження

- Пароль в HTML → технічно видно тому, хто відкриє «View Source» у браузері. Для звичайних клієнтів достатньо.
- Не використовуйте цей формат для конфіденційних даних.
